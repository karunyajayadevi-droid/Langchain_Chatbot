# Comparison Between Week 9 and Week 10 Chatbots

## Week 9 – Chatbot Development using Ollama

- Developed a basic interactive chatbot using Python and Ollama.
- Used direct Python code to communicate with the language model.
- Maintained conversation history within the chatbot session.
- Saved chatbot conversations into CSV files.
- Used a simple chatbot structure.

## Week 10 – LangChain Basics

- Developed a College Assistant Chatbot using LangChain and Ollama.
- Used reusable prompt templates with dynamic placeholders.
- Created five different prompt templates for different scenarios.
- Implemented a Summarization Chain and Question Answering Chain.
- Tested the chatbot using 20 different user queries.
- Saved chatbot responses and chain results into CSV files.
- Used a modular structure for managing prompts and model interactions.

## Key Differences

| Week 9 | Week 10 |
|---|---|
| Basic Python chatbot | LangChain-based chatbot |
| Direct model interaction | Prompt templates and chains |
| Simple prompt handling | Reusable prompt templates |
| Basic workflow | Modular workflow |
| Basic question answering | Multiple specialized tasks |

## Conclusion

Week 9 introduced the development of a basic local chatbot using Ollama. Week 10 improved the chatbot by integrating LangChain, reusable prompt templates, and different chains. LangChain makes the application more modular and easier to extend for future RAG and vector database integration.
